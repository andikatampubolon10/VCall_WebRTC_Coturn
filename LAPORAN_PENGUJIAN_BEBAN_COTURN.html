📊 Kesimpulan Evaluasi Kinerja & Skalabilitas Server

  • Tahap 1 s/d 3 (100–400 VUs): Menghasilkan SLA 100% sempurna dengan latensi di bawah 40 ms. Konsumsi CPU sangat rendah (< 17%) dan RAM di bawah 8%. Arsitektur berjalan dalam zona performa emas (golden zone).
  • Tahap 4 & 5 (800–1.200 VUs): SLA bertahan tinggi di 98.8%–99.5%. Latensi rata-rata mulai naik ke 62–94 ms akibat kepadatan antrean I/O event loop, namun masih jauh di bawah batas toleransi percakapan manusia (150 ms).
  • Tahap 6 (2.000 VUs / 1.000 Pasang): Merupakan Breaking Point (Batas Puncak) arsitektur saat ini. CPU mencapai 79.6% dan SLA turun ke 89.2% karena saturasi TCP backlog dan limit file descriptors Linux (1024 fd).

🛡️ Analisis Alokasi Port CoTURN & Sumber Daya Hardware

  • Ekspansi Port UDP Berhasil Penuh: Rentang port 10000–65535 sukses melayani ribuan alokasi dinamis tanpa benturan port (0 port collision) maupun kegagalan port exhaustion.
  • Efisiensi Memori Luar Biasa: CoTURN (berbasis C/C++ epoll) hanya mengonsumsi < 20% memori sistem (715 MB dari 4.0 GB) pada beban 2.000 user simultan.
  • Rekomendasi Skalabilitas Lanjutan: Untuk melayani > 2.000 VUs secara kontinu, disarankan meningkatkan batas file descriptor kernel Linux (ulimit -n 65535) dan TCP backlog (net.core.somaxconn = 4096).
